# Comment Category Prediction

## Overview

This project explores a machine learning approach to predicting comment categories using the Comment Category Prediction Challenge dataset.

The notebook covers exploratory data analysis, data preprocessing, model training, model comparison, evaluation, and generating predictions for the test dataset.

## Workflow

1. Load and inspect the training and test datasets.
2. Explore feature distributions, missing values, and target-class distribution.
3. Perform exploratory data analysis and feature preprocessing.
4. Train and compare multiple classification models.
5. Evaluate the best-performing model.
6. Generate predictions for the test dataset.

## Models

The notebook explores the following models:

* Logistic Regression
* Ridge Classifier
* SGD Classifier

A dummy estimator is also included as a baseline.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* scikit-learn
* Jupyter Notebook

## Dataset

The project uses the Comment Category Prediction Challenge dataset.

The notebook references the dataset through Kaggle input paths. The dataset is not included in this repository. Obtain it from the authorized competition source and update the file paths as necessary before running the notebook.

## Running the Notebook

1. Open the notebook in Kaggle, Google Colab, or Jupyter Notebook.
2. Install any missing dependencies.
3. Download or attach the dataset through its authorized source.
4. Update the dataset paths in the notebook.
5. Run the cells in order to reproduce the analysis, train the models, and generate predictions.
